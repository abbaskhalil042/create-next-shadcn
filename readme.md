# create-next-shadcn 🚀

Next.js + shadcn/ui starter with built-in dark mode support.

## Features

- ⚡ Next.js 14 (App Router)
- 🎨 shadcn/ui components pre-configured
- 🌓 Dark mode (system-aware)
- 📦 TypeScript ready
- 🔥 Zero-config setup

## Quick Start

```bash
npx create-nextjs-shadcn my-app
cd my-app
npm install
npm run dev
